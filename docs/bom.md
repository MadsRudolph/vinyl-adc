## Must be ordered

- **6.144MHz** (X1)
- **2x6 IDC** (J3, J4)
- **2x7 IDC** (J5, J6, J7)

## Sockets

Use DIP sockets for every IC (all stocked): 8-pin for the LM311s and
the oscillator can, 14-pin for the TL074s / 74HC04 / 74HC74 / 74HCT132,
16-pin for the 74HC157 / 74HC4040 / 74HC4049, 20-pin for the 74HC244.

## The board-to-board links

Three ribbons, all shrouded IDC box headers on 2.54 mm pitch:

| Cable | Header | Ways | Carries |
|---|---|---|---|
| common - digital | J3 / J4 | 2x6 | +5V, GND, MCLK, QL, QR, PUMP |
| common - channel L | J5 / J7 | 2x7 | both supplies, both references, CMP_L, DACP_L, DACN_L |
| common - channel R | J6 / J7 | 2x7 | the same, R |

You need 2 x 2x6 headers, 4 x 2x7 headers, and matching IDC
sockets and ribbon. The shop carries none of them, so they go on
the same order as the oscillator can. A bare pin header would fit
the same pads and would also plug in backwards -- which puts +5V
straight across the ground column. The shroud's key is what makes
that impossible, and it is the reason this is not a stocked part.
